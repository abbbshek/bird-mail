BirdMail is an email app

The core intention was to apply and practice Python OOP 

Run with `python main.py`

#### **Core Application Files:**

`main.py`: Interactive command line interface for the email client

`src/message.py`: Defines the Message class representing individual emails

`src/folder.py`: Manages collections of messages in memory

`src/storage.py`: Handles persistent storage using JSON files

`src/email_client.py`: Main business logic for email operations

`src/utils.py`: Utility functions for the application

`data/inbox.json`: Stores received messages

`data/sent.json`: Stores sent messages

`data/trash.json`: Stores deleted messages
